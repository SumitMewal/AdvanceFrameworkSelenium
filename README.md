# AdvanceFrameworkSelenium
Advanced Selenium Framework (Java + TestNG + ExtentReport + Docker and many more things) designed as a learning project from YouTube tutorials. @TestingMiniBytes @https://github.com/amuthansakthivel/amuthansakthivel

This repository contains an Advanced Test Automation Framework designed to support:

✔ Page Object Model (POM)
✔ Hybrid Framework Structure
✔ Data-Driven Testing
✔ Reusable Utility Methods
✔ Centralized Configuration Management
✔ Extent Report Integration
✔ TestNG Annotations & Parallel Execution

This project is ideal for learning, practice, and real-time automation understanding.

🎯 Purpose of This Project

This framework is created for learning and practice, inspired by YouTube Automation Tutorials (@TestingMiniBytes) @https://github.com/amuthansakthivel/amuthansakthivel, and try to adapt all and implement in the industry.

It is suitable for:

Automation practice

Interview preparation

Portfolio building

Selenium + Java learning
